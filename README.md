# zikao-english-trainer · 自考英语智能训练系统

基于国产大模型的自学考试英语（专升本）智能训练系统 —— 由一线英语教师借助生成式 AI（通义千问、DeepSeek）独立开发，将"两层定位法"阅读判断教学法软件化。

> 本仓库为教学案例开源版，包含核心前端脚本、后端接口实现与 2 套样例训练页面，供教师同行参考复现。

## 功能特性

- **AI 引导员**：进入题目先呈现题干与原文，引导学生自主思考后再分步展开"定位—比对—判断"解析
- **解题过程可视化**：题干关键词、原文证据句、语义映射点同色严格绑定，代词标注指代对象
- **AI 错因讲解**：答错时调用通义千问 API，针对"这名学生为什么会这样错"生成个性化诊断
- **AI 学情诊断 / 个性化分析面板**：实时统计 TRUE / FALSE / NOT GIVEN 三类判断正确率，错题一键回跳，随时生成综合诊断
- **点词释义**：点击任意英文单词，自动朗读并由大模型给出语境化中文释义
- **AI 答疑助教**：目录页内置对话窗，回答严格基于"两层定位法"教学方法论（方法论写入系统提示词）
- **学习激励**：作答音效、连对表扬、连错时本地识别错误模式并即时点拨
- **成绩留存**：每套成绩与历史最佳留存本机，目录页直接展示
- 全部 AI 生成内容标注"AI生成"，教师审核把关；移动端浏览器即开即用、零安装

## 技术栈

- 前端：原生 HTML / CSS / JavaScript，单文件页面，无构建依赖
- 后端：Node.js + Express，PM2 守护，nginx 反向代理
- 大模型：通义千问（qwen-plus / qwen-turbo，OpenAI 兼容接口）
- 内容生产：Python 批量生成脚本（"一套规则引擎，批量产出训练页面"）

## 部署说明

1. 静态页面：将训练页 HTML 与 `ai-explain.js` 置于任意静态目录（nginx / 任意静态托管均可）
2. 后端接口：参照 `docs/server-api.md` 将四个接口（ai-explain / ai-summary / word-lookup / ai-chat）加入 Express 服务，nginx 将 `/api/review/` 反代至该服务
3. 大模型密钥：通过环境变量 `QWEN_API_KEY` 注入（百炼平台申请），**切勿提交至代码仓库**
4. 页面接入：在训练页 `</body>` 前引入 `<script src="ai-explain.js"></script>` 即可获得全部 AI 功能

## 开发方法：需求文档驱动大模型编码

本系统由零编程团队的英语教师与国产大模型协作完成：每个功能先以自然语言写出详细需求文档（页面结构、数据格式、交互规则），交给大模型生成代码，教师负责试用、验收与迭代反馈。该工作流不依赖学科背景，任何教师均可复用。
